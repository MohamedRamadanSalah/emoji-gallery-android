# Emoji Gallery (Android)

![Android](https://img.shields.io/badge/Android-3DDC84?logo=android&logoColor=white) ![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white) ![minSdk](https://img.shields.io/badge/minSdk-23-blue) [![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

A native Android app in Java that shows a full-screen, immersive gallery of emojis. Tap any emoji to open its detail screen.

## Features

- Splash screen
- Emoji grid built with RecyclerView and a custom adapter
- Detail screen for each emoji
- Immersive full-screen mode that hides the system bars

## Tech stack

Java · Android SDK (minSdk 23, targetSdk 35) · RecyclerView · Material Components · Gradle (Kotlin DSL)
